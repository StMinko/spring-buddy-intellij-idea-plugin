Multiple writes without @Transactional

Reports non-test methods that perform multiple repository or persistence write operations without an apparent transaction boundary. A failure between writes can leave partially committed data. Add @Transactional at the service boundary unless the class or a private transactional caller already provides one.

Writes inside TransactionTemplate or TransactionOperations callbacks are excluded. A private helper is treated as covered only when it has an in-class caller and every caller path leads to a transaction boundary. Javadoc {@link} references do not count as callers.
