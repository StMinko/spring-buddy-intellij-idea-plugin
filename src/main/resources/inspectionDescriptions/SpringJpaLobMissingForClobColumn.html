Reports JPA fields that use @Column(columnDefinition = "CLOB"), BLOB, or MySQL large-object text types (TINYTEXT, MEDIUMTEXT, LONGTEXT) without @Lob. Plain TEXT, array types such as text[], and jsonb are not reported: PostgreSQL treats TEXT as an ordinary string column, and adding @Lob there switches Hibernate to large-object storage.

A database large-object column declaration alone does not tell JPA to bind the field with LOB semantics. Hibernate can use the wrong JDBC type or schema metadata and fail at runtime or truncate large values.

Add @Lob next to the @Column mapping. Use text fields for CLOB and binary fields such as byte[] for BLOB.
