Reports calls to the WebTestClient jsonPath(String, Object...) overload.

In Spring Framework 6 this overload formatted the extra arguments into the expression (expression.formatted(args)); it was deprecated and removed in Spring Framework 7, so the call no longer compiles.

A Hamcrest matcher passed there, as in expectBody().jsonPath("$.name", Matchers.is(1)), never asserted anything. Quick fix rewrites that call to jsonPath(expression).value(matcher).

Template arguments, as in jsonPath("$.items[%s].name", index), are rewritten to jsonPath("$.items[%s].name".formatted(index)), exactly what Spring 6 evaluated. The fix needs Java 15 or newer for String.formatted().
