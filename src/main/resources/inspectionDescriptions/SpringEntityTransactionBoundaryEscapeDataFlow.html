Reports when a JPA entity returned from a @Transactional method of the same class is later mutated or lazy-loaded by a non-transactional caller method in the same class.

Once the @Transactional proxy method returns, the persistence context is closed and the entity becomes detached. Any subsequent lazy getter call throws LazyInitializationException, and any setter call is silently lost (no dirty checking happens outside a session). Return a DTO or keep the access inside a @Transactional boundary.

A mutation is not reported when the same method later passes the entity variable to a repository save/saveAndFlush or EntityManager.merge, because that call writes the detached changes back.
