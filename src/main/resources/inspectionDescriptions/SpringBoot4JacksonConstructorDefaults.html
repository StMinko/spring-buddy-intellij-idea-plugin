Reports classes that expose both a no-arg constructor and a single public constructor with parameters while at least one field carries a field initializer.

Jackson 3 prefers a public all-args constructor as soon as parameter names are compiled in (-parameters), where Jackson 2 picked the no-arg constructor and applied setters on top. The all-args path bypasses the field initializers, so default values silently disappear from deserialized objects.

Quick fix adds @JsonCreator to the no-arg constructor. For Lombok @AllArgsConstructor/@NoArgsConstructor pairs it adds onConstructor_ = @JsonCreator to @NoArgsConstructor, unless that annotation already sets onConstructor; alternatively drop the initializer or set spring.jackson.use-jackson2-defaults=true while migrating.
