Predicts LazyInitializationException by detecting lazy getter calls on JPA entities outside @Transactional methods, where the entity was obtained from a repository or service call that loaded it inside a transaction.

A collection getter (getItems()) or entity getter that returns another JPA entity type triggers lazy loading. If the call is made after the original @Transactional method has returned, the Hibernate session is closed and LazyInitializationException is thrown at runtime. Use @Transactional on the caller, initialize the association eagerly (EntityGraph or JOIN FETCH), or return a DTO.

Direct lazy getter calls used only to read an entity's identifier are exempt. Private helpers are exempt when they have an in-class caller and every caller path reaches a transactional method. For directly loaded variables, associations named in the source repository method's JOIN FETCH query or @EntityGraph(attributePaths = ...) are treated as initialized; aliases are not followed for this fetch check.
