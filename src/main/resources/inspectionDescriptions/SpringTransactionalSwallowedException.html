Exception swallowed inside @Transactional method

Reports @Transactional methods with catch blocks that catch rollback-relevant exceptions and do not rethrow. Swallowed exceptions let the method return normally, causing the transaction to commit. Rethrow, mark rollback-only, or move error handling outside the transaction.

A catch block that ends with return is not reported when no repository or EntityManager write happens before or inside the try: the transaction holds no changes yet, so committing it is harmless.
